
## Tentang e-cashier-v2

Projek ini berisikan materi pembelajaran untuk pedoman latihan ukk yang berbasis website. dalam 
materi ini menggunakan teknologi laravel v10, alpine js, livewire, tailwindcss, flowbite
ada pun beberapa fitur yang akan dibangung

## LAYER ADMIN
- MANAGEMENT AUTHENTICATION ROLE USER (admin, chasier)
- CREATE PRODUCT
- DELETE PRODUCT
- RESTOCK PRODUCT
- UPDATE PRODUCT
- HISTORIES PRODUCT

## LAYER CASHIER
- CARD ORDER PRODUCT
- CARD LIST PRODUCT
